How to use?

1. WiFi settings

- If WiFi is not connected, then WiFi named "CCK_Recorder_X" would be activated.
- Connect to that WiFi, and WiFi setting page will be opened.
- If not opened, go to browser and go to url "192.168.4.1"
- Then, set the WiFi ssid and password!

2. Comp settings

- If progressing competition is only one, automatically set competition mode.
- Button "OK": Go before competition
- Button "+2": Go next competition
- Button "DNF": Set that competition mode

3. Judge register

- When message "Wait for judge", just tag judge's card!
- Be aware: If you don't have any account, you can't regist judge.
- If you want to change judge, just press button "Judge chan"!

4. Player register

- When message "Wait for player", just tag player's card!
- Then, device will display player's info, round, try count.
- Button "OK": Go to inspection section
- Button "Reset": Return to player register

5. Inspection/Running

- Just wait for player's timer start, automatically go to running section.
- If inspection over 15s, penalty automatically added.
- If inspection over 17s, automatically recorded as DNF.

6. Adjust record

- After solving, you can adjust record(such as penalty, DNF).
- Button "OK": Go to upload section
- Button "+2": Add penalty, could be duplicated
- Button "DNF": Record ad DNF
- Button "Reset": Revert timer's record

7. Upload record

- It needs player's confirm, just tag player's card!
- After try 4 at Ao5, display will show BPA5, WPA5.
- After complete round, display will show Single, Average.
